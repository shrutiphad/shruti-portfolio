# Shruti Phad: personal landing page

Local-only, separate from the fancy GTM portfolio and original source.

Run `npm start` from this folder, then open http://127.0.0.1:3002/.
No installation is required. Node serves the saved files in dist/.
Edit dist/index.html for content and links; edit dist/styles.css for appearance.
Photo and resume are in dist/assets/. `npm run check` checks the server syntax.

The small Click here button links to the local fancy site on port 3001.
Run `npm start` in ../comparison-v2 to start that site separately.
Neither website has been pushed or deployed. The original Downloads source
and the Portfolio baseline are protected reference copies.

The personal page uses its original warm dark background and serif font,
a narrow reading column and three expandable sections. Display copy is lowercase.
The exact supplied 649x773 portrait stays left, uncropped and narrower; the
conversation statement is two lines on laptop with social links below.
The closing line is: wait, i also have a fancy whiteboard portfolio.
The rounded button opens port 3001. The credit is right-aligned: crafted by shruti phad.
Writing copy describes personal brand strategy as an aspiration.

An alternate design is saved separately in ../personal-landing-preview on port 3003.
This folder retains the approved design. A pre-correction snapshot is in
../personal-landing-backups/2026-10-03-before-preview.
